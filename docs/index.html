Supported Formats & Owner Setup Guide

Supported Firmware Inputs

.zip, .rar, .7z, .tar, .tar.gz, .tgz, .tar.md5, .ozip, .ofp, .ops, .kdz, ruu_*.exe, payload.bin, super.img, UPDATE.APP, .pac, .nb0, .sin, system.new.dat*, *.img.zst

Owner Setup Checklist

  1. In GitHub Repo Settings → Secrets and variables → Actions, set TG_TOKEN and TG_CHAT (plus GH_PAT & GH_SSH_KEY for GitHub pushes, or GITLAB_TOKEN & GITLAB_SSH_KEY for GitLab).
  2. In Settings → Pages, set Source to GitHub Actions.
  3. To allow users to trigger dumps with only a firmware link (no GitHub login or PAT), deploy worker/ to Cloudflare Workers (npx wrangler secret put GH_TOKEN && npx wrangler deploy) and set relayUrl in docs/config.js.
